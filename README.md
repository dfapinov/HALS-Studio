# HALS Studio

**Holographic Acoustic Loudspeaker Scanner — Processing, analysis and virtual measurement**

HALS Studio is the processing and analysis half of the **HALS (Holographic Acoustic Loudspeaker Scanner)** — an open-source loudspeaker measurement system based on nearfield measurements and Spherical Harmonic Expansion (SHE).

Rather than treating each microphone measurement as an independent frequency response, HALS constructs a mathematical model of the acoustic field surrounding the loudspeaker. Once that model has been created, HALS Studio can separate the source and room fields, recover the loudspeaker's anechoic response, analyse its behaviour in 3D, and evaluate the reconstructed field at virtual microphone positions.

The HALS system consists of two applications:

**HALS Control — Part 1: Measurement**\
Controls the HALS measurement robot, audio interface and measurement sequence. It captures impulse responses around the loudspeaker together with key geometry and project metadata.

**HALS Studio — Part 2: Processing, Analysis & Export**\
Takes the measurement dataset produced by HALS Control and turns it into a 'holographic' acoustic model. Studio provides tools for inspecting and analysing the reconstructed sound field and an Export workspace for extracting FRD and impulse-response (IR) data for use in other applications.

---

# What makes HALS different?

A HALS measurement is not simply a collection of off-axis frequency responses.

Measurements taken over the surface surrounding the loudspeaker are used to construct a **continuous, physics-based spatial model** of the sound field rather than a collection of individual responses that exist only at the original microphone coordinates.

This is not interpolation. HALS models how the acoustic field propagates through 3D space.

## Sound Field Separation

One of the key capabilities of HALS is **Sound Field Separation (SFS)**.

Sound generated by the loudspeaker inside the measurement volume behaves differently in space from sound generated outside it by the room. By measuring the acoustic field over multiple positions and radii, the spherical-harmonic solver can distinguish these different spatial behaviours.

The measured field is separated into:

- an **Internal Source Field** — sound radiating from the loudspeaker inside the measurement volume;
- an **External Room Field** — sound generated outside the measurement volume, principally reflections and environmental noise.

This allows HALS to recover **reflection-free / anechoic loudspeaker data from measurements made in an ordinary room**.

The result is a continuous model that can be inspected directly in 3D or evaluated at almost any virtual microphone position.

HALS Studio is organised around three main workspaces.

**Process** turns the captured measurements into the holographic model.

**Analysis** provides tools for exploring the reconstructed sound field.

**Export** lets you take virtual measurements from the model and convert them into conventional acoustic measurement formats.

# Process

The measurement project produced by HALS Control passes through four main processing stages before it becomes the model used by the rest of HALS Studio.

The controls and diagnostics for each stage are available within the application and covered in greater detail in the documentation.

## Stage 1 — FDW & Smoothing

Stage 1 prepares the captured impulse responses for spatial modelling.

HALS applies **Frequency Dependent Windowing (FDW)** together with **complex frequency-domain smoothing**. This cleans up the data by reducing the influence of late reflections and comb filtering before moving on to the later processing stages, while retaining the complex magnitude and phase information required by the spatial processing.

## Stage 2 — Acoustic Origin Search

A spherical-harmonic model works most efficiently when its mathematical origin is close to the effective acoustic source. But a loudspeaker does not have one fixed acoustic origin. The dominant source can move between the tweeter, midrange, woofer and port with frequency.

Stage 2 tracks this changing acoustic origin as a function of frequency.

Despite the name, this has nothing to do with the acoustic measurements the user may later extract from the system. It is exclusively an internal mathematical optimisation used to keep the 'holographic' model well conditioned and avoid requiring unnecessary higher-order components.

The transformation is intended to be transparent to the user, other than running the process and checking that the results appear reasonable.

## Stage 3 — Find Order N

Spherical-harmonic **Order N** determines how much angular or spatial detail the model can represent.

Increasing the order allows progressively finer directivity features to be reconstructed, but eventually the measurement dataset no longer contains enough independent spatial information to support the additional complexity. Beyond this point, increasing the order can begin fitting noise, positioning errors or spatial aliasing as if they were genuine acoustic behaviour.

To identify a practical balance, Stage 3 performs trial reconstructions over a range of orders and uses several complementary diagnostics:

- **Source to Room Field Ratio** — how successfully the internal loudspeaker field remains separated from the external room field;
- **Sound Power Discarded** — how much modelled internal sound power would be omitted by stopping at a particular order;
- **Change to Directivity Pattern** — how much the reconstructed source directivity changes when another harmonic order is added.

These provide recommended maximum orders for the final solve while allowing the user to inspect the results and make the final selection.

## Stage 4 — Solve the Model

Stage 4 performs the full Spherical Harmonic Expansion.

The prepared, origin-aligned complex measurement data is solved across frequency to produce the spherical-harmonic coefficients describing the 3D acoustic field.

This is where the individual microphone measurements become the continuous **holographic sound-field model** used by HALS Studio.

The solve simultaneously separates the internally generated loudspeaker field from the external room field. The resulting model retains magnitude and phase and can subsequently be propagated and evaluated at positions other than the original measurement points.

Once Stage 4 is complete, the model is ready for **Analysis** and **Export**.

# Analysis

HALS Studio includes a suite of tools for exploring the spatial, frequency and time-domain behaviour of the reconstructed loudspeaker.

## 3D Directivity Balloons

Visualise the reconstructed radiation pattern as an interactive **3D directivity balloon**.

Rotate the model freely in three dimensions, move through frequency and inspect lobes, nulls and changes in radiation behaviour.

## Directivity Sonograms

Generate directivity maps in 2D and 3D for examining how dispersion changes with frequency.

## Directivity Globes

Directivity globes provide another intuitive view of how the loudspeaker radiates into 3D space.

## CTA-2034 / Spinorama

Generate standard **CTA-2034** loudspeaker datasets from the reconstructed model.

HALS can evaluate the required spatial coordinates and calculate the standard curves including:

- On-Axis
- Listening Window
- Early Reflections
- Sound Power
- Predicted In-Room Response (PIR)
- Directivity Indices (DI)

## Frequency & Phase Analysis

Inspect magnitude and phase at multiple selected positions using overlaid traces. An automatic fit line helps highlight overall response trends.

The legend can be dragged to a convenient location, and double-clicking a trace key selects that response for the cursor readout.

## Wavelet & CSD

HALS Studio includes both **wavelet analysis** and traditional **Cumulative Spectral Decay (CSD)** for examining resonances and decay over frequency and time.

CSD progressively removes the earlier part of the impulse response to show what remains, but this can also change constructive and destructive interference and occasionally produce unintuitive results. Wavelet analysis instead examines the response using frequency-scaled time windows, providing a more intuitive view of when energy occurs and how long it persists.

Both are particularly useful for revealing resonances and stored or delayed energy in the reflection-free HALS data.

# Export

The **Export workspace** turns the solved HALS model into a virtual acoustic measurement environment.

Set up virtual microphones wherever you need them, at the required distance and orientation relative to the loudspeaker, then export the resulting measurements for use in crossover-design software or other acoustic applications.

## Angular Sweeps

Define a radius, angular range and angular increment to generate conventional polar measurement sets. Sweeps can be created horizontally, vertically or both.

This is particularly useful for producing datasets for loudspeaker simulation and crossover-development software.

## CTA-2034 Extraction

The Export workspace can automatically evaluate the spatial coordinates required for a CTA-2034 dataset and calculate the corresponding standard curves.

This allows a complete Spinorama dataset to be generated at the click of a button.

## Custom Coordinates

For measurements that do not fit a conventional angular sweep, a custom set of coordinates can be specified and evaluated directly from the model.

Custom positions use spherical coordinates defined by **R, Theta and Phi**.

## Loudspeaker Geometry

When driver-position metadata has been recorded in HALS Control, the Export workspace can display the driver positions and baffle outline together with the virtual measurement geometry.

This makes it easier to define observation axes and understand where exported responses are being evaluated relative to the physical loudspeaker.

## Export File Formats

### FRD

Standard **FRD frequency-response files** can be exported containing magnitude and phase.

HALS preserves the dense native frequency grid of the processed data rather than reducing it to typical sparse octave-resolution frequency points.

Time-of-flight phase can optionally be removed, making the underlying phase response easier to inspect while preserving relative phase relationships within an exported measurement set.

### Impulse Responses

As the model retains full complex pressure information, it can also be exported as **impulse responses (IRs)**.

IR exports retain the physical time-of-flight propagation delay, behaving like an impulse response captured by a real microphone at the chosen virtual position.

# Installation

## Windows Installer — Recommended

For normal use, the Windows installer is the easiest way to run HALS Studio.

1. Open the **Releases** section of this repository.
2. Download the latest HALS Studio Windows installer.
3. Run the installer.
4. Launch **HALS Studio** from the Start Menu or installed shortcut.

> **HALS Studio is under active development.** Versions may change project compatibility, processing options or user-interface behaviour.

---

# Running From Source

HALS Studio currently targets Windows.

## Requirements

- Windows 10/11
- Python **3.14**
- Git

## Clone the Repository

```powershell
git clone https://github.com/dfapinov/HALS-Studio.git
cd HALS-Studio
```

## Install

Run:

```text
install.bat
```

This creates a local `.venv` virtual environment and installs the required Python packages.

## Launch

Run:

```text
launch.bat
```

Analysis and Export tools become available once suitable processed project/model data has been loaded.
